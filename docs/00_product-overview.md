# AIキャリアスターターキット｜Product Overview

## 1. プロジェクト概要

### プロジェクト名
AIキャリアスターターキット

### コンセプト
AIを知るための無料プレゼントではなく、
**自分に合うAI活用方法を知り、7日間で実際に行動を始めるためのスターターキット。**

診断結果をもとに、

- 自分に向いているAI活用
- 強み
- 注意ポイント
- 向いている仕事
- おすすめAIツール
- 学習順
- 今日やること
- 7日ロードマップ
- 30日後の目標
- 90日後の方向性

まで提示する。

診断をして終わりではなく、
**診断 → 行動 → 報告 → フィードバック → 次の学習**
までを1つの体験として設計する。


---

# 2. このプロジェクトの目的

## ユーザー側の目的

ユーザーが、

「AIを使いたいけど何から始めたらいいか分からない」

という状態から、

「自分は何をすればいいか分かった」

さらに、

「実際に最初の一歩を動けた」

という状態になること。


## 事業側の目的

AIキャリアスターターキットを、
MOMOKAブランドの主要なリスト獲得導線として使用する。

主な目的は以下。

1. オープンチャット参加者を増やす
2. 公式LINE登録者を増やす
3. ユーザーの悩みを収集する
4. ユーザーのAI活用目的を把握する
5. 7日間の行動データを取得する
6. Udemyへの導線を作る
7. Brainへの導線を作る
8. 今後の商品開発に使えるデータを集める
9. 将来的なコミュニティ参加者候補を増やす


---

# 3. MOMOKAブランドとの位置づけ

MOMOKAのブランドコンセプトは、

**AIで「作る → 売る → 仕事にする」を、自分で実践しながら教える。**

AIキャリアスターターキットは、
そのブランドへの最初の入口として位置づける。

無料プレゼントだけで収益化を完結させるのではなく、

SNS
↓
無料プレゼント
↓
リスト
↓
Udemy
↓
Brain
↓
その他商品
↓
将来的なコミュニティ

という商品導線の起点にする。

# 4. 想定ターゲット

AIキャリアスターターキットは、
「AI副業初心者」だけに限定しない。

以下の層を広く対象とする。


## AI初心者

- ChatGPTをほとんど使ったことがない
- AIに興味はあるが何をすればいいか分からない
- AIツールが多すぎて選べない


## AIを少し使っている人

- ChatGPTは使ったことがある
- 文章作成などには使っている
- 仕事への活かし方が分からない
- 何を学べばいいか分からない


## 本業でAIを活用したい人

- 会社員
- 個人事業主
- フリーランス
- 経営者

など。

主なニーズは、

- メール
- 要約
- 資料
- 企画
- リサーチ
- 業務効率化


## 副業・収益化したい人

- AIを使って副業したい
- 在宅ワークを始めたい
- 制作案件を取りたい
- AIを使った商品を作りたい
- AIを使ったサービスを販売したい


## すでに制作している人

- Web制作
- Canva
- SNS
- 画像生成
- 動画
- GPT
- アプリ
- 自動化

などを触っているが、

「どう仕事にするのか」

で止まっている人。

# 5. 診断コンセプト

診断名称（仮）

**AI仕事診断**

または

**AI仕事診断書**

ユーザーの知識量を測定する診断ではない。

目的は、

**「あなたはAIをどう使うと成果につながりやすいか」**

を判定すること。


---

# 6. 診断結果の基本構造

診断では、

**5タイプ × 3目的**

を判定する。


## 5タイプ

### 1. AIスマートワーカー

仕事効率化タイプ。

キーワード：

- ChatGPT仕事活用
- メール
- 要約
- リサーチ
- 企画
- 資料
- 情報整理
- 業務効率化


### 2. AIクリエイター

制作タイプ。

キーワード：

- Web制作
- LP
- Canva
- デザイン
- 画像
- 動画
- コンテンツ制作


### 3. AIサポーター

支援・代行タイプ。

キーワード：

- SNS運用
- AI事務
- オンライン秘書
- リサーチ
- ライティング
- 資料作成
- クライアントワーク


### 4. AIプロデューサー

商品化・販売タイプ。

キーワード：

- note
- Brain
- Udemy
- PDF
- 教材
- テンプレート
- コンテンツ販売


### 5. AIビルダー

仕組み化・開発タイプ。

キーワード：

- Codex
- GPT
- Webアプリ
- 自動化
- 業務改善
- AIツール
- システム


---

# 7. 3つの目的

ユーザーのAI活用目的を以下の3つに分類する。


## WORK

本業活用

目的：

- 今の仕事を効率化したい
- AIを実務で使いたい
- AIスキルを仕事に活かしたい


## SIDE

副業・収益化

目的：

- AIを使って収入を作りたい
- 副業を始めたい
- 商品・サービスを販売したい
- 案件を取りたい


## BOTH

本業＋副業

目的：

- まず仕事でAIを使いたい
- 将来的に収益化もしたい
- 本業で得たAI経験を副業にも活かしたい

# 8. 診断結果で表示する内容

診断終了後、以下を表示する。


## MAIN TYPE

最もスコアが高かったタイプ。


## SUB TYPE

2番目にスコアが高かったタイプ。


## GOAL

本業活用 / 副業・収益化 / 両方。


## AI活用スコア

5タイプすべてのスコアを表示する。

例：

仕事効率化：82

制作：91

サポート：48

商品化：69

仕組み化：76


## STYLE

スコア差によって表示。

例：

- 特化型
- ハイブリッド型
- マルチAI活用型

# 11. オープンチャットの役割

オープンチャットは、

**広い見込み客リスト**

として使用する。

役割：

- AIに興味がある人を集める
- 診断を提供する
- MOMOKAを知ってもらう
- 次の行動として公式LINEへ移動してもらう


---

# 12. 公式LINEの役割

公式LINEは、

**オープンチャットより濃い見込み客リスト**

として扱う。

公式LINEに来るためには、

1. 診断
2. 結果確認
3. スクリーンショット
4. LINE追加
5. メッセージ送信

という行動が必要。

この行動をしたユーザーは、
オープンチャット参加者より関心度が高いと考える。


---

# 13. 公式LINEで送ってもらう内容

ユーザーには以下を送ってもらう。


## 1. 診断結果スクリーンショット

MAIN TYPE

SUB TYPE

GOAL

が確認できるもの。


## 2. 今一番変えたいこと

自由回答。

例：

- AIを仕事で使えるようになりたい
- 副業を始めたい
- Web制作を仕事にしたい
- 商品を作りたい
- AIで何をすればいいか分からない

# 19. 7日チャレンジ共通仕様

各Dayには必ず以下を含める。


## 今日のテーマ

何をする日なのか。


## なぜやるのか

この行動の意味。


## 今日やること

具体的な行動。


## 完成条件

どこまでできたら終了か。


## 使用する補助特典

必要に応じて、

- プロンプト
- AIツール
- チェックリスト

を指定。


## つまずいたときのヒント

初心者向け補助。


## LINE報告

ユーザーが送る内容。

例：

Day1完了！

今日やったこと：
○○

気づいたこと：
○○
