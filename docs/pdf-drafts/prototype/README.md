## 確認方法

各HTMLファイルをブラウザで直接開いて確認します。

- 画面上部の「実寸（A4）」ボタン：A4固定レイアウトを実寸相当で表示
- 画面上部の「スマホ幅縮小」ボタン：同じA4ページ要素を `transform: scale()` で約380px幅相当に縮小表示

印刷確認時はブラウザの印刷機能でA4・余白なしを指定してください。`@page { size: A4; margin: 0; }` を設定しています。
