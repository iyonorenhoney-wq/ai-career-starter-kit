## 修正必須の部分

### 1. P-06（ターゲット整理）のCUSTOM欄に誤りがある

**現在どうなっているか**
P-06のPROMPTには空欄が2つある。

```
作るジャンル：[ここに書く]
今考えているターゲットのイメージ（あれば）：[ここに書く]
```

しかしCUSTOM欄は次のようになっている。

```
CUSTOM
[ここに書く]2箇所をDay1で決めたジャンルに書き換えて使用
```

**なぜ問題なのか**
2つの空欄のうち、1つ目（作るジャンル）はDay1の内容で埋めれば正しいが、2つ目（今考えているターゲットのイメージ）はDay1とは無関係で、読者自身が「今の時点で思っているターゲット像」を書く欄である。CUSTOM欄の説明どおりに両方へ「Day1で決めたジャンル」を書いてしまうと、2つ目の欄の意味が成立しない。初心者ほど説明文をそのまま信じて書き写す可能性が高く、誤読を誘発する。

**どう直すのが良いか**
CUSTOM欄を2つの空欄それぞれに対応させる。例：「1つ目の[ここに書く]をDay1で決めたジャンルに、2つ目の[ここに書く]を今考えているターゲット像（なければ「特になし」でよい）に書き換えて使用」

### 2. 30日ロードマップ（WEEK1〜4）に「売る」に相当するステップが1つもない

**現在どうなっているか**
P.23のWEEK1〜4は、WEEK1（1作品目公開）→WEEK2（2作品目）→WEEK3（3作品目＋ポートフォリオ着手）→WEEK4（ポートフォリオ完成＋発信強化）と、**すべて「作る」で構成**されている。「売る」に相当する行動（値段をつける・提案する・仕事として声をかける）は一切登場せず、90日ロードマップで唐突に「初案件／商品化／制作サービス」へジャンプする。

**なぜ問題なのか**
2点の理由で単なる「バランスの悪さ」ではなく矛盾と言える。

1. `resultTypes.creator.cautions`（P.09「注意ポイント」に掲載）には「作ることが目的になる：作品を作り続けても、公開・販売・営業しなければ仕事にはつながりません」「発信・営業を後回しにする：作品を作ったら、必ず『見せるところ』までを1セットにします」と明記されている。現在の30日ロードマップは、**この注意ポイントが警告している失敗パターンそのもの**（作り続けるだけで営業・発信をしない）を読者に推奨してしまっている。
2. MOMOKAブランドの核心コンセプトは`docs/00_product-overview.md`§77で「AIで『作る → 売る → 仕事にする』を、自分で実践しながら教える」と定義されている。creator_side（副業・収益化）のBOOKであるにもかかわらず、Day1〜30日のあいだ「売る」の実践機会が一度もないのは、このブランドの核心と噛み合っていない。

すでにP-08（価格設定・提案文）・P-09（SNS発信文）というプロンプトを用意しているにもかかわらず、30日ロードマップのどこでいつ使うのかが一切示されていないのも同じ問題の裏返し。

**どう直すのが良いか**
WEEK2かWEEK3のどこかに、「作った作品をもとにP-08で値段を考えてみる」「P-09で発信してみる」といった小さな「売る」体験を1つ組み込む。無理に本格的な受注を目指す必要はなく、「値段を考えてみる」「知人に見せてみる」程度の小さな一歩で十分（cautionsの「値段をつけるのが苦手」への直接対応にもなる）。

## 修正を推奨する部分

### 1. P.10「向いているAI活用」と「向いている仕事」のタグがほぼ同じ内容の言い換えになっている

**現在どうなっているか**
`useCases`（12件）と`jobs`（10件）を2つのタグリストとしてそのまま並べている。Web制作／LP制作／SNSデザイン／バナー／画像／動画／資料など、8割前後の項目が両方のリストに（表現だけ変えて）重複して登場する。

**なぜ問題なのか**
1ページの中で似た単語の羅列を2回読まされる形になり、「AI活用」と「仕事」の違いが読者に伝わりにくい。情報量が増えているように見えて、実質的な新情報はほとんどない。

**どう直すのが良いか**
片方のリストに寄せて簡潔にするか、「AI活用」は使う場面（Web制作のときにこう使う、等の一言）、「仕事」は収益につながる文脈（案件・依頼のされ方）で明確に書き分ける。既存データ自体（`resultTypes.ts`）は変更できないため、PDF側の見せ方・抜粋の仕方で差別化する。

### 2. P-08のINPUT EXAMPLEに、本書のツール一覧にない固有名詞（Figma）が唐突に出てくる

**現在どうなっているか**
P-08のINPUT EXAMPLEに「納品物：Figmaデータ＋公開URL」とある。Figmaは本書のツール一覧（T-01〜T-06：ChatGPT/Claude/Gemini/Canva/Codex/画像生成AI）に一度も登場しない。

**なぜ問題なのか**
`06_pdf-spec.md`§30が定める「ツール情報は書きすぎない」方針や、本書がツールを絞り込んで案内している設計意図と噛み合わない。初心者が「Figmaって何？自分は使ってないけど大丈夫？」と不安になる可能性がある。

**どう直すのが良いか**
本書のツール一覧に含まれる表現に置き換える（例：「デザインデータ一式＋公開URL」、あるいはCanvaを明示）。

### 3. 「機密情報を入力しない」という注意書きがP-10だけにあり、同じ仕事効率化カテゴリのP-11〜P-13にはない

**現在どうなっているか**
P-10（メール作成）の【前提】にのみ「機密情報や個人情報は入力しないでください」とある。P-11（議事録・要約）、P-12（資料構成）、P-13（タスク整理）は業務内容や打ち合わせメモを貼り付けさせる設計だが、同様の注意書きがない。

**なぜ問題なのか**
P-11〜13は実際の業務メモやタスク（取引先名・案件内容等を含みうる）を貼り付ける前提のプロンプトであり、P-10と同等かそれ以上に機密情報が混入しやすい。この20本は全15ルート共通の補助特典として使い回される設計であり、特に「_work」系ルートで使われる際にこの注意書きの有無のばらつきが問題になりやすい。

**どう直すのが良いか**
P-11〜P-13の【前提】に同様の一言を追加し、仕事効率化カテゴリ内で表記を統一する。

### 4. Day5（制作）の負荷がDay中最大にもかかわらず、WORK欄が最も薄い

**現在どうなっているか**
Day5のWORK欄は「進捗チェック欄（着手／半分／完成）」のみ。他のDay（1,2,3,4,7）は具体的な記入欄や複数の質問が用意されているのに対し、Day5は実質的な制作支援がP-04（詰まったときの壁打ち・受動的サポート）だけになっている。

**なぜ問題なのか**
Day5は「実際に制作する」という7日間で最も時間と労力のかかる工程であり、ジャンル（特にWeb・動画など）によっては1日で70〜80%へ到達するのが難しい場合もある。にもかかわらず、能動的な進め方のガイドがなく、詰まったときの受け身の支援しかない。

**どう直すのが良いか**
「制作の進め方」の簡単なチェックリスト（例：骨格を作る→肉付けする→見た目を整える、の3段階）を追加するか、Day5・Day6の間に多少の融通（「時間がかかるジャンルの場合はDay6にまたがってもよい」といった一言）を入れる。

## 削除／統合を検討する部分

### 1. P.24（AIツール早見表）とP.11（おすすめAIツール）の内容が大きく重複している

**現在どうなっているか**
P.11はcreator向けに5〜6ツール（ChatGPT/Claude/Canva/画像生成AI/Codex）を詳しく紹介し、P.24（全冊共通の早見表）は5ツール（ChatGPT/Claude/Gemini/Canva/Codex）を一覧で示す。両者の重複は5つ中4つ（Geminiのみ差分）。

**なぜ問題なのか**
P.11から約13ページ離れた場所で、ほぼ同じ内容を再び読ませることになる。全体ページ数を圧縮したい場合の候補になる。

**どう直すのが良いか**
P.24をcreator_sideでは大幅に簡略化する（Geminiの行だけ追加情報として残す等）か、他ルートとの共通化を優先するならP.24はそのまま残しP.11側で「詳しくはP.24も参照」と誘導する程度に留める。どちらも致命的ではないため、ページ数調整の必要が出た場合の候補として扱う。

### 2. 「1つ決めてください」というメッセージがP.04→P.14→Day1で3回連続する

**現在どうなっているか**
P.04（7日間ロードマップ全体像）で「DAY1 制作ジャンルを決める」と予告し、直後にP.05〜P.13（タイプ理解ページ群）を挟んでP.14（TODAY MISSION）で再び「7日以内に完成させる作品を1つだけ決めてください」と伝え、さらにP.15（Day1本編）でもう一度同じ指示を出す。

**なぜ問題なのか**
致命的ではないが、同じ「決めてください」という指示を短い間隔で3回読まされる格好になり、単調に感じられる可能性がある。

**どう直すのが良いか**
軽微なため必須ではないが、P.14の文言をP.04・Day1と少し差別化する（「さあ、始めましょう」程度の橋渡しに留める等）とテンポが良くなる。

## 不足している部分

### 1. P.06「SUB TYPEについて」の本文が、実際には一度も書かれていない

**現在どうなっているか**
STEP Aの状態表ではP.06は「確定」と表記されているが、v1〜v3のどの版でも「SUB TYPEとは何か、の一般説明＋案内文」という**内容の説明**が書かれているだけで、実際にページに載せる文章そのものは一度も執筆されていない（P.03・P.04は下書き文まで書いたが、P.06は書いていない）。

**なぜ問題なのか**
「確定」ラベルと実態が一致していない。加えて、P.03がすでに「あなたのSUB TYPE・STYLE・AI活用スコアは、診断結果画面で確認できます」と案内しているため、P.06で改めて同じ案内をそのまま書くと重複になる（上記「削除／統合を検討する部分」とも関連）。

**どう直すのが良いか**
P.06はP.03と重複しない範囲（SUB TYPEという概念そのものの一般的な説明、「MAINを強める第二の武器」という考え方）に絞って本文を新規に書く。あるいはP.03へ統合しページを1つ減らす案も検討に値する。

### 2. 30日ロードマップに「売る」の具体的なチェックポイントがない（前述「修正必須②」の裏返し）

上記「修正必須」の2番目と同一の欠落。P-08・P-09という「次のステップで使う」プロンプトが存在するのに、30日ロードマップのどのタイミングで使うのかが一度も明示されていない。
