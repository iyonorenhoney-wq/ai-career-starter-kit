## STEP A-7｜30日／90日ロードマップの再設計（今回の中心的な修正）

### 設計方針

- creator_sideの7日→30日→90日を、**「7日＝作る／30日＝見せる・売る行動を経験する／90日＝改善しながら育てる」**という一本のストーリーにする
- 「30日以内に必ず売上を作る」ことはゴールにしない。ゴールは**本人が実行できる行動**（完成させる・人に見せる・発信する・価格を考える・販売につながる行動を1回以上する・反応を見て改善する）
- P-08（価格設定・提案文）／P-09（SNS発信文）を**いつ使うか30日ロードマップの中で明示**する
- 90日は「実践→反応を見る→改善→再提案／再発信→育てる」というサイクルとして描く

### P.23｜30日ロードマップ

```
30日ロードマップ

WEEK1（Day1〜7）
作る
　→ 1作品目を完成させ、公開する。
　　このBOOKの7日間そのもの。

WEEK2
見せる・売るを経験する

　・完成した作品を、Day7よりも広く発信する
　　SUPPORT PROMPT：P-09（SNS発信文）

　・作品に価格をつけて考えてみる
　　SUPPORT PROMPT：P-08（価格設定・提案文）

　・提案・出品など、販売につながる行動を
　　1回以上やってみる
　　（知人に見せて感想をもらう、
　　　スキルシェアサービスに出品してみる、など）

　※ このWEEKのゴールは「売れること」ではありません。
　　「見せる」「価格を考える」「行動する」を
　　実際にやってみることがゴールです。

WEEK3
反応を見て、改善する

　・WEEK2での反応を振り返る
　　（反応があってもなくても、事実として記録する）

　・振り返りをもとに、2作品目に着手する
　　（1作品目より少しだけ良くする）

WEEK4
積み上げる

　・3作品目に着手し、
　　簡易ポートフォリオの骨組みを作る

　・3作品を揃え、
　　簡易ポートフォリオを完成させる
```

### DAY5｜制作（WORK強化版）

| 項目 | 内容 |

| WHY | 完璧を目指すと手が止まる。今日は完成させる日、磨くのは明日（Day6）と決めておくと動きやすい。 |
| ACTION | Day4の構成をもとに実際に制作する。まず完成優先。 |

```
INPUT EXAMPLE

```

```
【私の情報】

制作にかかった時間の目安：[ここに書く]
難易度（自分の感覚でよい）：[ここに書く]

・制作時間が長いほど、難易度が高いほど、修正対応が多いほど、価格を上げる要因になりやすい
```

## v4完成時の確認

### 7日→30日→90日が一本のストーリーになっているか

```
7日（Day1〜7）＝ 作る
　制作ジャンルを決め、ターゲットを考え、参考作品を集め、
　構成を作り、制作し、改善し、公開する。

30日（WEEK2〜4）＝ 見せる・売るを経験する
　WEEK2で、公開した作品を発信し（P-09）、
　価格を考え（P-08）、販売につながる行動を1回以上する。
　WEEK3で反応を振り返り、2作品目に活かす。
　WEEK4で3作品＋簡易ポートフォリオを揃える。

90日 ＝ 育てる
　実践→反応を見る→改善→再提案／再発信、
　というサイクルで作品・サービス・発信を育てていく。
```

**確認結果**：Day7の「公開」（作る の最終ステップ）から、WEEK2の「見せる・売るを経験する」へ直接つながっており、90日の「育てる」サイクルも、WEEK2〜3で一度経験した「発信→反応→改善」の小さなサイクルを、90日間で繰り返し拡大していく形になっている。一本のストーリーとして接続できている。

### 「売る＝必ず売上を出す」になっていないか

WEEK2の本文に「このWEEKのゴールは『売れること』ではありません。『見せる』『価格を考える』『行動する』を実際にやってみることがゴールです」と明記した。90日ロードマップの末尾にも「どの形に育つかは人によって異なります。断定せず、『育て方の流れ』として示しています」と明記しており、成果を保証しない書きぶりになっている。`06_pdf-spec.md`§94の免責文（適性・収益等を保証しない）とも整合している。
