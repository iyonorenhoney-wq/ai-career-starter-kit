### A-1｜P.02 この攻略BOOKの使い方（本文確定）

**役割整理**：P.02＝「このBOOKをどう使うか」（読み方の姿勢を伝える）、P.04＝「7日間で何をするか」（Day1〜7の地図を見せる）。P.02では7日/30日/90日を**大枠のみ**述べ、7日間の中身（Day1〜7の各テーマ）には立ち入らず、詳細はP.04に委ねる。

```
この攻略BOOKの使い方

このBOOKは、
一度読んで終わる資料ではありません。

あなたの診断結果をもとに、

今日
　↓
7日
　↓
30日
　↓
90日

の順番で進めるための実践ガイドです。

AIクリエイターとして副業・収益化を目指すあなたにとって、
この7日・30日・90日は、こう進みます。

7日：まず1つ作る
　↓
30日：人に見せる・売るための行動を経験する
　↓
90日：反応を見ながら改善し、育てる

まずは全部読もうとせず、
今日のページから始めてください。

（7日間で具体的に何をするかは、
　次のページ「7日間ロードマップ全体像」で確認できます）
```

`06_pdf-spec.md`§12の基本文言をベースに、creator_side向けの3段階の流れを追加した。最後の一言でP.04への橋渡しを明示し、役割の重複を避けている。

### A-2｜P.23 30日ロードマップ（WEEK2に具体例を追加）

**変更理由**：「販売につながる行動を1回以上する」だけでは初心者が何をすればいいか分からない可能性があるため、「自分の作品・スキルを必要な人へ届ける行動」だと分かる短い具体例を追加した。ジャンルごとに細分化はせず、どのジャンルでも当てはまりやすい5例に絞っている。

```
30日ロードマップ

WEEK1（Day1〜7）
作る
　→ 1作品目を完成させ、公開する。
　　このBOOKの7日間そのもの。

WEEK2
見せる・売るを経験する

　・完成した作品を、Day7よりも広く発信する
　　SUPPORT PROMPT：P-09（SNS発信文）

　・作品に価格をつけて考えてみる
　　SUPPORT PROMPT：P-08（価格設定・提案文）

　・「自分の作品・スキルを必要な人へ届ける行動」を
　　1回以上やってみる

　　例：
　　・制作サービスとして提案してみる
　　・SNSで作品と「制作できます」を発信する
　　・スキル販売サービスへ出品してみる
　　・テンプレートや素材として販売してみる
　　・知人やモニターへ提案してみる

　※ このWEEKのゴールは「売れること」ではありません。
　　「見せる」「価格を考える」「行動する」を
　　実際にやってみることがゴールです。

WEEK3
反応を見て、改善する

　・WEEK2での反応を振り返る
　　（反応があってもなくても、事実として記録する）

　・振り返りをもとに、2作品目に着手する
　　（1作品目より少しだけ良くする）

WEEK4
積み上げる

　・3作品目に着手し、
　　簡易ポートフォリオの骨組みを作る

　・3作品を揃え、
　　簡易ポートフォリオを完成させる
```

### A-3｜P-08 INPUT EXAMPLE（汎用化）

**変更理由**：Creatorの制作ジャンルはWeb／LP／Canva／SNS／バナー／画像／動画と幅広く、「Canvaで作成」という特定ツール限定の表現は、他ジャンルを選んだ読者に当てはまらない。具体性は残しつつ、ツール名を外した。

```
INPUT EXAMPLE（修正後）
作品の種類：LP制作／制作時間：約10時間／難易度：中（初めてのジャンル）
修正対応：2回まで／納品物：完成データ一式＋公開URL／利用範囲：商用利用可
```

「作品の種類：LP制作」という例自体は1つの具体例として残し（すべてのジャンルを網羅する必要はない）、納品物の説明のみツール名を含まない表現にした。

### A-4｜P.38 次のステップ（仮）CTA文言修正

**変更理由**：制作原稿（`creator_side_manuscript_v1.md`）を作成する過程で、P.38の末尾「先行案内を受け取りたい場合は、公式LINEをそのまま登録しておいてください」という文言が、読者の実際の状況と噛み合わないことが判明した。本BOOKの読者は、`docs/HANDOFF.md`§9の受け取りの流れ（診断→スクショ→公式LINE追加→送信→BOOK受け取り）のとおり、**すでに公式LINEを追加した状態でこのBOOKを受け取っている**。「登録しておいてください」という依頼は、すでに登録済みの読者には不自然なため、「特に何もしなくてよい、そのまま待っていればよい」という趣旨の文言に修正した。

この文言はv3で確定して以降、v4・v5では「変更なし」として本文を再掲していなかった（本文の正本はv3にのみ存在していた）ため、今回あらためてv5側にも全文を明記する。

```
次のステップ（仮）

7日間、お疲れ様でした。

ここから先は、
選んだ制作ジャンルによって
向いている次の一歩が変わります。

Web／LP制作を選んだ方へ
→ AI Web制作を仕事にしていくための
　 実践キットを、別途ご案内する予定です。

Canva／SNS／バナー／画像・動画制作を選んだ方へ
→ それぞれのジャンルに合わせたご案内を、
　 今後準備していきます。

現時点で、ジャンル別の商品ラインナップは
確定していません。

今後の先行案内も、
公式LINEからお届けします。

楽しみにお待ちください。
```

変更したのは末尾2文のみ（「先行案内を受け取りたい場合は、公式LINEをそのまま登録しておいてください」→「今後の先行案内も、公式LINEからお届けします。楽しみにお待ちください。」）。それ以外の本文・ジャンル別の案内内容・ページの役割は変更していない。

**`NEXT_PUBLIC_LINE_URL`の`.env.local`未設定について**：この変更とは別件として、`docs/HANDOFF.md`§10のとおり本番公開前に必ず設定が必要な項目として残っている。今回の資料制作は止めず、**公開前チェック項目**として申し送る。
