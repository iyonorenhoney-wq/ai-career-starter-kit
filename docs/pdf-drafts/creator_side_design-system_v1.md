## ①｜39ページのページタイプ分類

39ページを内容の「形」で分類すると、**11種類のレイアウトパターン**に整理できる。ご提案の8カテゴリ（表紙／タイプ解説／情報整理・説明／7日チャレンジ・ワーク／ロードマップ・図解／プロンプト集／チェックリスト／CTA・最後のメッセージ）を出発点に、実際のページ内容を照らし合わせた結果、次の3点で細分化・統合した。

- 「タイプ解説」は実際には**3種類の異なる見た目**（ヒーロー型／読み物型／カードグリッド型）に分かれる
- 「情報整理・説明」も**3種類**（読み物型／タグリスト型／テーブル型）に分かれる
- 逆に「CTA／最後のメッセージ」は独立させず、**読み物型に統合**できる（構造は「見出し＋本文」で共通、トーンが違うだけ）
- 診断ルート・TODAY MISSIONのような「大きな1メッセージだけを見せるページ」は、どのカテゴリにも当てはまらないため**新設**（ステートメント型）

## ②｜必要な共通テンプレート（11種）とその設計方針

各テンプレートについて、「このテンプレート内で変動する要素（＝creator_side固有のテキストや個数）」と「固定される構造（＝15冊すべてで共通のレイアウト骨格）」を分けて設計する。これにより、1冊目専用の作り込みにならず、残り14冊でも骨格を流用できる。

| # | テンプレート | 固定される構造（15冊共通） | 変動する要素（ルートごとに差し替え） | 補足 |
| --- | --- | --- | --- | --- |
| ① | 表紙 | レイアウト・ロゴ位置・配色 | MAIN TYPE名／GOAL名／Diagnosis ID欄 | 15冊で最も差し替え箇所が少なく、機械的に量産しやすい |
| ② | ステートメント | 余白比率・文字サイズの階層 | 見出し文言・本文（1〜3行） | P.03はMAIN×GOAL固定文言、P.14は5タイプ共通データ（`firstAction`）を差し込むだけ |
| ③ | 読み物・説明 | 見出し＋リード文＋本文のブロック構造 | 本文テキスト量（可変長に対応できる余白設計が必須） | CTA（P.38）とクロージング（P.39）はこのテンプレートの「トーン違いバリエーション」として扱う |
| ④ | タイプ紹介 | アイコン／モチーフ配置枠・キャッチコピーの見せ方 | 5 MAIN TYPE分のテキスト・アイコン | **15冊中5種類しか実体がない**（同じMAINなら3冊で完全に同じ中身）。最初に精度を上げる価値が最も高い |
| ⑤ | カードグリッド | カード数（3〜6枚）に対応できるグリッド／カード内の見出し+本文構造 | カードの枚数・各カードの文言 | 強み(5)／注意ポイント(5)／ツール(5-6)で枚数がほぼ揃うため、1つの可変グリッドで対応可能 |
| ⑥ | タグ／チップリスト | チップの折り返しレイアウト | チップの個数・文言・2リスト構成かどうか | P.10は2ブロック構成、P.13は1ブロックのみという違いに対応できる可変設計にする |
| ⑦ | テーブル／早見表 | 列見出し・行の可変対応 | 行データ（用途→ツール） | 15冊で完全共通の内容（Tool ID T-01〜T-05）なのでテンプレートと中身がほぼ一体化してよい |
| ⑧ | ロードマップ／フロー図 | 「シンプル型」（P.04, P.12：一直線の矢印つきリスト）と「詳細型」（P.23, P.24：各ステップに複数行のサブ項目を持つ）の**2サブバリエーション** | ステップ数・各ステップの文言・サブ項目の有無 | 詳細型は今回のWEEK2のようにサブ項目＋プロンプト参照が入るため、シンプル型より縦に伸びる前提でレイアウトする |
| ⑨ | 7日チャレンジ・ワークシート | THEME/WHY/ACTION/WORK/SUPPORT/DONE CONDITION/LINE REPORTの7ブロック構造＋チェックボックス | WORK欄の記入欄の形（自由記述／選択式／STEP分解） | **15冊×7〜8ページ＝100ページ以上で使う最頻出テンプレート**。Day5のようにWORK欄がSTEP1〜4に分かれるケースにも対応できる可変ブロックにしておく必要がある |
| ⑩ | プロンプトカード | WHEN/PROMPT/CUSTOM/INPUT EXAMPLEの4ブロック＋ID/CATEGORYラベル | PROMPT本文の長さ（P-08のように6ブロック分の見出しを含む長いものから、P-01のような短いものまで） | INDEXページ（表形式＋共通ルール）は本カードとは別のサブパターンとして設計。**20本すべてが全冊共通の資産**なので、このテンプレートの完成度が15冊展開に最も効いてくる |
| ⑪ | チェックリスト | チェックボックス＋ラベルの並び | 項目数・判断フロー図の有無 | P.36は判断フロー図付き、P.37はシンプルな日数チェックのみという違いに対応 |

## ③｜最初にデザイン確認すべき代表ページ

全39ページを順番に作るのではなく、**11テンプレートそれぞれについて「最も内容が複雑・最も再利用価値が高いページ」を1枚ずつ選び、先に確認する**。ここで確認しておけば、同テンプレートの残りのページは「型に流し込むだけ」になり、後戻りのリスクが最小化できる。

| 優先度 | テンプレート | 代表ページ | 選定理由 |
| --- | --- | --- | --- |
| 最優先 | ⑨ 7日チャレンジ・ワークシート | **P.19（DAY5）** | 全39ページ中もっとも登場回数が多い（8回）テンプレート。かつSTEP1〜4のサブ構造を持つ最も複雑なケースなので、ここで確認できれば残り7ページは低リスク |
| 最優先 | ⑩ プロンプトカード | **P-08（価格設定・提案文）＋P.26（INDEX）** | 20本のプロンプトは全15冊で使い回す共通資産。P-08は6項目の入力欄を持つ最長パターンで、これが収まればP-01〜20すべて対応可能。INDEXは表形式の別パターンとして別途確認 |
| 高 | ④ タイプ紹介 | **P.05（MAIN TYPE）** | 15冊中5種類しか実体がないほど再利用価値が高い。ブランドの第一印象を左右するページでもある |
| 高 | ① 表紙 | **P.01** | 15冊すべての最初のページ。ここが決まらないと他の制作に着手しづらい |
| 中 | ⑧ ロードマップ／フロー図 | **P.23（30日ロードマップ）** | 「詳細型」サブバリエーションの中でも情報量が最も多い（WEEK2にプロンプト参照＋具体例5つを含む）。これが収まれば90日・7日間全体像・学習順も収まる |
| 中 | ⑤ カードグリッド | **P.09（注意ポイント）** | 5枚のカード中もっとも本文が長いパターン |
| 中 | ③ 読み物・説明 | **P.06（SUB TYPEについて）** | 5ページ中もっとも本文量が多い読み物ページ |
| 中 | ② ステートメント | **P.03（診断ルート）** | BOOKの中で最も「第一印象」の重みが大きいページ |
| 低 | ⑥ タグ／チップリスト | **P.10** | 2ブロック構成でP.13より複雑 |
| 低 | ⑦ テーブル／早見表 | **P.25** | 唯一の実例だが15冊共通資産のため確認価値は高い |
| 低 | ⑪ チェックリスト | **P.36** | 判断フロー図付きでP.37より複雑 |

**合計11ページ**（P.26を含めると12ページ）で全テンプレートを一度検証できる。

## ④｜39ページへの展開・制作順序

ページ番号順ではなく、**テンプレート単位でまとめて量産する**順序を提案する。同じ型を連続して作ることでCodexとのやり取りが安定し、後から全体の統一感を揃えやすい。

```
Phase 1｜代表ページでのデザイン確認（11〜12ページ）
　上記③の代表ページを1枚ずつ確認し、11テンプレートを確定させる

Phase 2｜テンプレート単位での量産
　1. 表紙（P.01）
　2. タイプ紹介（P.05）
　3. ステートメント（P.03, P.14）
　4. 読み物・説明（P.02, P.06, P.07, P.38, P.39）
　5. カードグリッド（P.08, P.09, P.11）
　6. タグ／チップリスト（P.10, P.13）
　7. テーブル／早見表（P.25）
　8. ロードマップ／フロー図（P.04, P.12, P.23, P.24）
　9. 7日チャレンジ・ワークシート（P.15〜P.22、8ページ）
　10. プロンプトカード（P.26〜P.35、10ページ）
　11. チェックリスト（P.36, P.37）

Phase 3｜39ページ通し確認
　ページ番号順に最初から最後まで読み、
　・ページ間の参照整合性（Prompt ID・Tool IDの一致等）
　・流れの自然さ（7日→30日→90日のストーリー）
　・デザインの一貫性
　を確認する

Phase 4｜残り14冊への展開に向けた監査
　Phase 1〜3で確定したテンプレートの中に、
　creator_side固有の内容がハードコードされていないか
　（変数化すべき箇所が地の文に埋め込まれていないか）を確認してから
　2冊目（他ルート）の制作に着手する
```

**Phase 2の順序の考え方**：登場回数が少なくシンプルなテンプレート（表紙・タイプ紹介・ステートメント）から着手し、複雑で分量の多いテンプレート（7日チャレンジ・プロンプトカード）を後半に回すことで、シンプルな型で制作の勘所を掴んでから量の多い作業に入れるようにしている。
