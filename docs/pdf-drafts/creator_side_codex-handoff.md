> Claude Code側での設計作業はここまで。39ページ（基準）の実制作（dododo資料スキル）はCodex側で行う。

> **v3での更新**：①MOMOKAキャラクターの配置基準を「固定ページ数」から**「ページの機能で判断」**に変更し、10種類のポーズ選択ルールを追加。②ページ数は**39ページを基準としつつ、スマホ可読性のため必要なら増ページ可**と明記（文字を小さくする・内容を削るのではなく、ページ分割を優先）。詳細は`creator_side_design-spec_v1.md`§4-8・§0-1を参照。

## 2. Codexへ最初に送る指示文（そのままコピーして使用可）

```
creator_side攻略BOOK（39ページ基準）を、dododo資料スキルを使って制作してください。

【参照ファイル（この順番で読むこと）】
1. docs/pdf-drafts/creator_side_manuscript_v1.md
   → 39ページの制作原稿。これを正本として使用する。
2. docs/pdf-drafts/creator_side_design-spec_v1.md
   → ブランドカラー・フォント・余白・コンポーネントのデザインシステム仕様。
   → §0-1にページサイズ仕様、§4-8にMOMOKAキャラクターの運用ルールがある。
3. docs/pdf-drafts/creator_side_design-system_v1.md
   → 39ページのページタイプ分類（11種類の共通テンプレート）。

【ページサイズ（最重要の前提）】
- ページサイズはA4縦ではなく、スマホ縦型「1080×1920px（9:16）」を採用する。
  PDF書き出しは1px=1ptとして扱い、1080pt×1920ptのページとして書き出すこと。

【ページ数は39ページを基準とし、固定しない】
- 39ページはあくまで基準。文章・意味・ページ構成はmanuscript_v1.mdを正本として変更しないが、
  ページ面積が小さくなったことで内容が窮屈になる場合は、
  文字を小さくする・内容を削るのではなく、必ずページ分割を優先すること。
- 情報量の多いページ（DAY5／30日・90日ロードマップ／P-08プロンプトカード等）は
  分割が必要になりやすい。分割した場合は完了報告に必ず含めること。
- 最終的に何ページになるかは、実際に39ページ全体を組んでみた結果で決まってよい。

【MOMOKAオリジナルキャラクターについて】
- 配置するページ数をあらかじめ固定しない。design-spec_v1.md §4-8の「配置基準」
  （表紙／セクションの切り替わり／重要ポイント／注意事項／行動を促すページ／達成・完了ページ）
  に照らして、ページの内容に意味を持つ箇所だけに配置すること。基準に当てはまらない
  ページ（カード・タグが多く視覚要素が密なページ、記入欄中心のページ等）には配置しない。
  全ページへの機械的な配置はしないこと。
- キャラクターは10種類程度のポーズ素材を用意する予定（基本案内／PC作業／指差し／
  ひらめき／考える／応援／OK／スマホ／説明・プレゼン／達成・喜び）。
  §4-8のポーズ対応表を参照し、ページの内容に応じて意味のあるポーズを選ぶこと。
  装飾目的で機械的に同じポーズを繰り返し配置しないこと。
- キャラクター画像そのものが未提供の場合は、配置スペース（§4-8のサイズ・位置ルール）だけを
  確保した仮組みとして進めてよい。画像が届き次第、差し替える前提で進める。

【絶対に守ること】
- creator_side_manuscript_v1.mdの文章・意味・ページ構成を、独自判断で変更・要約・追加しないこと。
- レイアウト上どうしても原稿どおりに収まらない場合や、デザイン上どうしても変更が必要な場合は、
  勝手に変更・削除せず、変更が必要な箇所と理由を報告すること（ページ分割もこれに該当する）。
- ブランドカラーは白・黒・ネイビー・ターコイズの4色を基調とする（design-spec_v1.md準拠）。
  タイプ別の紫・緑・オレンジ等の色分けは使用しない。

【最優先すること】
- 単に本文をページへ流し込むのではなく、manuscript_v1.mdの各ページに定義されている
  「ページの役割」「一番伝えたい結論」「図解にした方が伝わる内容」「強調したい言葉」
  「読者に感じてほしいこと」「次ページへのつながり」を優先し、
  BOOK全体を通して視覚的な強弱・ページごとの役割の違いが伝わる資料にすること。
- この攻略BOOKは公式LINEから受け取り、主にスマートフォンで閲覧・実践される。
  スマホ縦型（1080×1920px）のPDFとして制作し、実寸表示したときに拡大操作なしで
  読める可読性を最優先すること（文字サイズ・余白・図解の視認性・チェックボックスや
  記入欄のサイズを含む。具体的な数値はdesign-spec_v1.md §2・§3・§5参照）。

【制作完了後に報告すること】
1. 最終的に何ページになったか（39ページから変わった場合はその内訳）
2. 使用したファイル・生成物の保存場所
3. スマホ閲覧時の確認結果
4. 文字切れ・はみ出し・レイアウト崩れの有無
5. 原稿から変更した箇所がある場合は、その箇所と理由（ページ分割・キャラクター配置ページの判断を含む）
6. PDF化前に確認すべきポイント

まず資料制作まで進め、完成報告をしたところで一度停止してください。
```
