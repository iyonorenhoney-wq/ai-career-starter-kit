### STEP A-3｜P.04（旧・空白レーダーチャート）の置き換え提案

**削除して統合する案（案1）**と、**別コンテンツへ置き換える案（案2）**を比較した上で、**案2を推奨**する。

| | 案1｜P.03へ統合（1ページ減） | 案2｜「7日間ロードマップ全体像」に置き換え（推奨・採用） |
| --- | --- | --- |
| 内容 | P.03のルート表示ページの下半分にミニフロー図を添える程度 | Day1〜7のテーマを1枚で俯瞰できるロードマップ図の独立ページ |
| メリット | ページ数が減る | 「これから何をするか」が1ページで見渡せ、7日間の完走イメージを最初に持てる。`06_pdf-spec.md`が重視する「読みやすい→分かりやすい→行動できる」の導線に合致し、Day3緩和などと同じ「完走率優先」の方針とも一致する |
| デメリット | ページが増えない代わりに、行動への橋渡しが弱くなる | ページ数は維持（削減にはならない） |

**理由**：ページ数はすでに35〜40ページを許容する方針（修正4）のため、無理に1ページ減らす必要がない。それよりも、P.03（診断ルートの確認＝行動宣言）から直接Day1へ飛ぶより、間に「7日間の地図」を挟むほうが完走率に寄与すると判断した。

```
7日間ロードマップ全体像

DAY1 制作ジャンルを決める
DAY2 ターゲットを決める
DAY3 参考作品を集める
DAY4 AIと構成を作る
DAY5 制作する
DAY6 改善する
DAY7 公開する

7日後のゴール：
人に見せられる作品を1つ完成させる。
```
