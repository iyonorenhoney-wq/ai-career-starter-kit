# AIキャリアスターターキット｜Result Combinations

## 1. ファイル概要

### ファイル名
`04_result-combinations.md`

### 目的
AI仕事診断で算出される、

**MAIN TYPE × SUB TYPE**

の組み合わせごとの専用結果文章を定義する。

5タイプから、

MAINとSUBは必ず異なるタイプになるため、

順序付き組み合わせは、

```text
5 × 4 = 20パターン
```

存在する。

この20パターンすべてに専用文章を持たせることで、

- 診断結果の納得感
- 自分専用感
- スクリーンショットしたくなる体験
- PDFの特別感
- 公式LINEへ進みたくなる動機

を高める。

# 4. MAINとSUBの意味

## MAIN TYPE

そのユーザーの現在のAI活用方向で、

最も強く出ている軸。


## SUB TYPE

MAIN TYPEを補完する、

第二のAI活用方向。


---

# 5. 順番には意味がある

以下は別結果として扱う。

```text
creator × builder
```

と

```text
builder × creator
```


理由：

`creator × builder`

は、

**「作る」が軸で「仕組みにする」が補助。**


`builder × creator`

は、

**「仕組みにする」が軸で「作る」が補助。**


同じ2タイプでも、

最初に進む方向が異なる。

# 8. smart_worker × creator

## Combination ID

```text
smart_worker_creator
```


## 表示名称

**実務 × 制作タイプ**


## ONE LINE

**仕事を整えながら、必要なものを自分で形にできる人。**


## DESCRIPTION

あなたは、

AIを毎日の仕事へ取り入れる
**「実務活用」**

を軸にしながら、

必要なものを実際に作る
**「制作力」**

も持っています。

単にAIで仕事を早くするだけではなく、

- 資料
- デザイン
- Web
- コンテンツ

など、

仕事に必要な成果物まで
自分で形にしていける組み合わせです。

まずは今の仕事を効率化しながら、

「自分で作ればもっと良くできるもの」

を探すと強みを活かしやすくなります。


## STRENGTH

- 実用性を考えて制作できる
- 作ることが目的になりにくい
- 現場で本当に必要なものを見つけやすい
- AI活用を成果物へつなげやすい

- 営業資料
- プレゼン
- Webページ
- 社内資料
- SNS素材
- 業務用コンテンツ


## WATCH OUT

効率化も制作もできるため、

やることを増やしすぎないこと。

まずは、

**「今の仕事で一番効果が出るもの」**

から始めます。


## FIRST DIRECTION

```text

↓

↓

```

# 28. STYLE別表示ルール

組み合わせそのものを強調する。

# 38. 最重要原則

MAIN × SUBを表示する理由は、

診断を複雑に見せるためではない。


目的は、

ユーザーが、

```text
私はただの「制作タイプ」じゃなくて、

制作を軸にしながら、
仕組みにするのも好きなんや
```

と、

**自分の特徴をより具体的に理解すること。**


最終的には、

```text
診断結果
↓
自分の特徴を理解
↓
自分に合うルートを知る
↓
7日間動く
```

ところまでつなげる。
