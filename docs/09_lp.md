# AIキャリアスターターキット｜Landing Page Specification

## 1. ファイル概要

### ファイル名
`09_lp.md`

### 目的

AI仕事診断へユーザーを誘導するための、

**診断LPの構成・コピー・CTA・導線・デザイン方針**

を定義する。

このLPの目的は、

商品販売ではない。

最初の目的は、

**「診断を受けてみたい」**

と思ってもらうこと。


その後、

```text
LP
↓
診断
↓
結果
↓
公式LINE
↓
専用PDF
↓
7日チャレンジ
```

へつなげる。


---

# 2. LPの役割

このLPは、

AIキャリアスターターキットへの入口。

ユーザーに対して、

```text
自分は何から始めればいい？

↓

まず診断してみよう
```

という流れを作る。


---

# 3. 最重要CTA

LPでの最重要CTAは、

**診断開始**

のみ。


基本CTA：

```text
無料でAI仕事診断をはじめる
```


補足：

```text
全10問
約2〜3分
無料
```


---

# 4. LPで売らないもの

LPでは、

以下を前面に出しすぎない。


```text
Udemy

Brain

コミュニティ

有料商品
```


理由：

入口では、

**診断を受けること**

だけに集中させる。

以下の悩みを拾う。


```text

何から始めればいいか分からない

ChatGPTは使っているけど、
仕事にどうつなげればいいか分からない

AI副業に興味はあるけど、
自分に何が合うか分からない

どれを覚えればいいか分からない

実際の行動につながらない

方向性が決まらない
```

掲載許可を得た声が集まれば追加。


例：

```text
「AIで何をしたらいいか分からなかったけど、
7日後には○○までできた」
```

# 76. お客様の声で優先するもの

```text
診断が当たった
```

だけでは弱い。


理想：

```text
診断後に行動できた

実際に何か作れた

仕事で使えた

方向が決まった
```

# 77. LPの最終ゴール

ユーザーがLPを読み終わった時に、

```text
この人すごそう
```

だけでなく、

**「とりあえず診断してみよ」**

となること。

# 78. LP完成基準

以下を確認。


```text
3秒で何のサイトか分かる

誰向けか分かる

診断したくなる

結果が気になる

専用BOOKが欲しくなる

7日チャレンジに魅力を感じる

CTAが迷わない

スマホで読みやすい
```

# 79. 最重要原則

LPで、

無料プレゼントの価値を、

**「PDF○ページプレゼント！」**

だけで表現しない。


今回の価値は、

```text
診断

↓

自分の方向が分かる

↓

自分専用ルート

↓

7日間行動

↓

小さな成果
```


という体験そのもの。


LPでも、

**情報量ではなく「変化」**

を見せる。
