# AIキャリアスターターキット｜PDF Specification

## 1. ファイル概要

### ファイル名
`06_pdf-spec.md`

### 目的
AI仕事診断の結果をもとに配布する、

**あなた専用AIキャリア攻略PDF**

の構成・デザイン・生成方法・共通パーツ・個別パーツ・補助特典を定義する。

このPDFは、

単なる診断結果資料ではなく、

**診断 → 理解 → 行動 → 7日チャレンジ → 30日 → 90日**

まで進める実践ワークブックとして制作する。


---

# 2. PDFの位置づけ

PDFは、

「無料特典のおまけ」

ではない。

AIキャリアスターターキットの中核コンテンツとして扱う。


ユーザー体験：

```text
AI仕事診断
↓
診断結果
↓
スクリーンショット
↓
公式LINE
↓
今一番変えたいことを送信
↓
専用PDF受取
↓
7日チャレンジ
↓
LINE報告
```


PDFの役割は、

**診断結果を、実際の行動へ変えること。**


---

## メイン名称

**AIキャリア攻略BOOK**

# あなた専用 AIキャリア攻略BOOK

# 4. PDFの個別化

全員に同じPDFは配布しない。

ユーザーから見ると、

**自分専用PDF**

になるようにする。


主な個別化要素：

- 診断結果ID
- MAIN TYPE
- SUB TYPE
- STYLE
- GOAL
- AI活用スコア
- MAIN × SUB説明
- MAIN TYPE解説
- GOAL解説
- MAIN × GOALロードマップ


---

# 5. PDF生成の基本構造

Ver.1では、

15冊を完全個別でゼロから制作するのではなく、

**パーツを組み合わせて生成する設計**

とする。


基本構成：

```text
共通パート

+

MAIN TYPEパート

+

SUB TYPEパート

+

MAIN × SUBパート

+

GOALパート

+

MAIN × GOALロードマップ

+

共通補助特典

+

次のステップ
```

# 30. ツール情報の注意

AIツールの仕様は変化するため、


# 103. PDF制作優先順位

最初から15冊全部デザインしない。


順番：

```text

PDF共通テンプレート

↓

Creator × SIDEで完全版を1冊制作

↓

3
実際にスマホで読む

↓

4
修正

↓

5
テンプレート確定

↓

6
残り14ルートへ展開
```


理由：

最初から15冊作ると、

後からデザイン修正が発生した場合に
15冊全部直すことになるため。

# 105. PDFの価値基準

PDF完成時に、

以下を確認する。


```text
有料でも買いたいと思える？

保存したい？

あとで見返したい？

実際に書き込める？

今日何をするか分かる？

7日間続けられそう？

次の学習へ進みたい？
```


1つでも弱ければ改善する。


---

# 106. 最重要原則

PDFの目的は、

情報量で驚かせることではない。


ユーザーに、

```text
自分のことが分かった

↓

何をすればいいか分かった

↓

今日1つ動けた

↓

7日間続けられた
```

という体験を作ること。


「無料なのに情報が多い」

ではなく、

**「無料なのに、本当に前へ進めた」**

と思われるPDFを目指す。
