# AIキャリアスターターキット｜Result Types

## 1. ファイル概要

### ファイル名
`04_result-types.md`

### 目的
AI仕事診断で使用する5タイプの正式な結果文章を定義する。

このファイルでは、

- タイプ名称
- キャッチコピー
- 一言診断
- 基本説明
- 強み
- 注意ポイント
- 向いているAI活用
- 向いている仕事
- おすすめAIツール
- おすすめ学習順
- 最初の一歩
- 30日後の方向性
- 90日後の方向性
- MAIN TYPE表示文
- SUB TYPE表示文
- MAIN × SUBの考え方

を管理する。

7日ロードマップ詳細は、

`05_roadmaps.md`

で管理する。


---

# 2. 共通方針

この診断では、

「あなたは絶対この仕事に向いている」

とは断定しない。

使用する表現：

- 〜の傾向があります
- 〜と相性が良いタイプです
- 〜から始めると進みやすいです
- 〜を強みにしやすいです
- 〜を試してみる価値があります


避ける表現：

- 必ず成功する
- 適職はこれ
- この仕事しか向いていない
- これをすれば稼げる
- 才能がある
- 成功率○%

# 4. AIスマートワーカー

## Type ID

```text
smart_worker
```


## Short

```text
SW
```


## 正式名称

**AIスマートワーカー**


## カテゴリ

**仕事効率化タイプ**


## 英語表示

```text
AI SMART WORKER
```


## キャッチコピー

**AIで、仕事をもっと速く・軽く。**


---

## 一言診断

あなたは、

**AIを「新しい仕事を作る道具」としてだけではなく、
今ある仕事をより良くするために使うと力を発揮しやすいタイプです。**


---

## あなたはこんなタイプ

あなたは、

情報を整理したり、
複雑なことを分かりやすくしたり、

「どうすればこの仕事をもっと早く進められるか」

を考えることと相性が良いタイプです。

AIを使うなら、

いきなり難しいことへ挑戦するより、

普段行っている、

- メール
- 情報整理
- 要約
- 企画
- 資料
- リサーチ

などから取り入れることで、

成果を感じやすくなります。

AIを「たまに質問するもの」ではなく、

**毎日の仕事を一緒に進める仕事道具**

に変えていくことが、
あなたの最初のテーマです。


---

## 強み

### 1. 情報を整理する

バラバラな情報を、

必要な形に整理することと相性があります。


### 2. 実務へ落とし込む

新しいAIツールを知るだけではなく、

「自分の仕事ならどこで使える？」

と考えやすいタイプです。


### 3. 小さな改善を積み重ねられる

いきなり大きな仕組みを作らなくても、

1つずつ仕事を改善していくことで成果を出しやすいです。


### 4. 文章系AI活用と相性が良い

メール、

要約、

文章整理、

企画、

資料構成などにAIを取り入れやすい傾向があります。


### 5. AIを実用ツールとして使いやすい

「AIを使うこと」より、

「仕事を終わらせること」

を目的にしやすいタイプです。


---

## 注意ポイント

### 1. 効率化だけで終わる

仕事が早くなって満足し、

そのAIスキルを次の成長につなげないことがあります。


### 2. AIへ任せすぎる

文章や資料をそのまま使用せず、

最終確認する習慣が必要です。


### 3. AIツールを増やしすぎる

複数ツールを覚えるより、

まず1〜2個を仕事で使える状態にすることを優先してください。


### 4. 自分のAIスキルを過小評価しやすい

普段当たり前にしているAI活用が、

他の人にとって価値になる場合があります。


### 5. 使うことが目的になる

AIを使った回数ではなく、

「何が早くなったか」

「何が良くなったか」

を見ることが重要です。

## キャッチコピー

---

## 一言診断

あなたは、

**AIを使って「考える」だけより、
実際に何かを作ることで力を発揮しやすいタイプです。**


---

## あなたはこんなタイプ

あなたは、

頭の中で考え続けるより、

実際に、

- Web
- デザイン
- 画像
- 動画
- 資料
- コンテンツ

などを作ることで理解が深まりやすいタイプです。

AIは、

質問に答えてもらうだけの存在ではなく、

**一緒に制作するパートナー**

として使うことで強みが出やすくなります。

最初から完璧な作品を作る必要はありません。

作る。

↓

見直す。

↓

修正する。

この繰り返しが、
あなたの成長につながります。


---

## 強み

### 1. アイデアを形にしやすい

考えて終わるのではなく、

実際の成果物へ変えることと相性があります。


### 2. 作りながら学べる

勉強してから始めるより、

実際に制作しながら必要な知識を学ぶ方が進みやすいです。


### 3. 完成物を積み上げられる

作ったものが、

そのまま、

- 実績
- ポートフォリオ
- 商品
- 発信素材

になります。


### 4. AIを組み合わせやすい

文章、

画像、

デザイン、

コードなど、

複数のAIを組み合わせることで力を発揮できます。


### 5. 改善によって伸びやすい

1回で完成させるより、

フィードバックをもらいながら改善することで成長しやすいです。


---

## 注意ポイント

### 1. 作ることが目的になる

作品を作り続けても、

公開・販売・営業しなければ仕事にはつながりません。


### 2. 次々作り始める

1つ完成する前に、

次のアイデアへ移らないよう注意。


### 3. 完璧になるまで公開しない

70〜80%でも一度出して、

反応を見ながら改善する考え方が重要です。


### 4. 値段をつけるのが苦手になりやすい

制作時間ではなく、

相手に提供する価値も考える必要があります。


### 5. 発信・営業を後回しにする

作品を作ったら、

必ず「見せるところ」までを1セットにします。

## あなたはこんなタイプ

---

## 強み

### 1. 相手の困りごとを考えられる

自分中心ではなく、

相手が必要としているものを考えやすいです。


### 2. クライアントワークと相性が良い

依頼内容に合わせて対応する働き方と相性があります。


### 3. AIで作業を短縮できる

人を支える作業を、

### 4. 継続仕事につながりやすい

---

## 注意ポイント

価値まで安くする必要はありません。


### 3. 相手に合わせすぎる

対応範囲を決めることが重要です。


### 4. 作業代行だけになりやすい

将来的には、

改善提案などもできると価値が上がります。


### 5. 自分の得意分野を決めない

最初は幅広く試しても、

最終的には1〜2分野に絞ることを検討します。

## あなたはこんなタイプ

あなたは、

同じ作業を何度もしていると、

**「これ、人が毎回やる必要ある？」**

と考えるタイプ。

AIを、

単なる会話ツールではなく、

- GPT
- Codex
- Webアプリ
- 自動化
- 社内ツール

などへ広げて使うことで、

最初から大きなシステムを作る必要はありません。

小さな不便を、

1つずつ仕組みに変えるところから始めます。


---

## 強み

### 1. 問題を構造的に見やすい

作業全体を分解し、

どこを改善できるか考えやすいです。


### 2. 効率化と相性が良い

繰り返し作業を減らすことへ興味を持ちやすいです。


### 3. AIを道具として広げやすい

ChatGPTだけでなく、

コードや自動化へ進みやすいです。


### 4. 高付加価値な仕事へ発展できる

単純作業ではなく、

「仕組みそのもの」を提供できる可能性があります。


### 5. 試行錯誤を価値に変えられる

エラーを直す過程そのものが、

経験として蓄積されます。


---

## 注意ポイント

### 1. 必要以上に複雑にする

本当に必要な機能だけ作ること。


### 2. 技術を学ぶことが目的になる

「何を解決するか」

を先に決めます。


### 3. 誰も求めていないものを作る

作る前に、

実際の困りごとを確認してください。


### 4. 完成まで時間をかけすぎる

最初は、

最低限使えるもの

を目標にします。


### 5. 便利さを説明できない

技術の説明ではなく、

「何がどう楽になる？」

を伝える必要があります。

# 11. MAIN × SUB文章の基本ルール

文章は、

