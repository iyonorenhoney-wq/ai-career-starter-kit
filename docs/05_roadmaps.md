# AIキャリアスターターキット｜15 Roadmaps

## 1. ファイル概要

### ファイル名
`05_roadmaps.md`

### 目的
AI仕事診断の結果で分岐する、

**5タイプ × 3目的 = 15ルート**

の行動ロードマップを定義する。

このファイルでは、

- ルートID
- 対象タイプ
- 対象GOAL
- 7日後のゴール
- 今日やること
- Day1〜Day7
- 30日後の目標
- 90日後の方向性
- 今やらなくていいこと
- つまずいたときの考え方
- 次の商品導線

を管理する。

各Dayの、

- 詳細解説
- 図解
- ワーク
- 使用プロンプト
- LINE報告文

はPDF制作フェーズでさらに掘り下げる。

# 3. 共通ロードマップ構造

すべてのルートは、

以下の順番で構成する。


```text
診断結果

↓

今日やること

↓

Day1〜Day7

↓

7日後の状態

↓

30日後の目標

↓

90日後の方向性

↓

```


---

# 4. 各Day共通仕様

各Dayには、

以下を必ず持たせる。


## TODAY THEME

今日のテーマ。


## WHY

なぜこの行動をするのか。


## ACTION

今日やる具体的なこと。


## DONE CONDITION

どこまでできたら完了か。


## SUPPORT

必要に応じて、

- プロンプト
- AIツール
- チェックリスト
- 図解

を使用。


## LINE REPORT

LINEへ送る報告内容。


---

# 5. 所要時間

各Dayの基本所要時間は、

```text
15〜30分
```

を目安とする。


目的：

**忙しい人でも7日間完走できること。**

# 6. 7日チャレンジの思想

7日間で、

その分野を完全に習得させることが目的ではない。


目的は、

**最初の小さな成果を作ること。**


例：

```text
AIを仕事で使った

作品を1つ完成させた

サービス候補を1つ決めた

商品案を作った

小さな仕組みを作った
```

# ROUTE 01
# AIスマートワーカー × 本業活用

## Route ID

```text
smart_worker_work
```


## MAIN TYPE

AIスマートワーカー


## GOAL

本業活用


## ルートテーマ

**ChatGPTを「たまに使う」から、
仕事の中で自然に使える状態へ。**


---

## 7日後のゴール

仕事の中に、

**AIを使う場面を3つ作る。**


---

## 今日やること

普段の仕事を5〜10個書き出す。

その中から、

```text
文章
整理
要約
調査
企画
```

に関係する仕事へ印をつける。

最後に、

**最初にAIを試す仕事を1つ決める。**


---

## Day1｜仕事を棚卸しする

### WHY

AI活用は、

ツールから考えるのではなく、

自分の仕事から考える必要がある。


### ACTION

普段行っている仕事を、

5〜10個書く。

例：

- メール
- 会議
- 資料
- 調査
- 顧客対応
- 報告
- 企画


その中から、

AIを使えそうな仕事を3つ選ぶ。


### DONE CONDITION

AIを試す仕事を1つ決める。


### LINE REPORT

```text
Day1完了！

AIで最初に変えたい仕事：
○○
```


---

## Day2｜文章作成にAIを使う

### ACTION

実際の、

- メール
- チャット
- 案内文
- 説明文

のどれか1つをAIと作る。


### DONE CONDITION

自分で確認・修正し、

実際に使える文章を1つ完成。


### LINE REPORT

```text
Day2完了！

AIで作ったもの：
○○

いつもより楽だった点：
○○
```


---

## Day3｜情報を整理する

### ACTION

実際の、

- 会議メモ
- 長文
- 資料
- 情報

をAIへ渡し、

```text
要点
重要事項
次の行動
```

に整理する。


### DONE CONDITION

AIで整理した情報を1つ作る。


---

## Day4｜AIを壁打ち相手にする

### ACTION

仕事で今考えている、

- 企画
- 問題
- アイデア

を1つ選ぶ。

AIと最低3往復会話する。


### DONE CONDITION

自分だけでは出なかった案を1つ見つける。


---

## Day5｜たたき台を作る

### ACTION

AIを使って、

- 資料構成
- 企画書
- 説明文
- マニュアル

などのたたき台を1つ作る。


### DONE CONDITION

仕事で使えるレベルまで修正。


---

## Day6｜自分専用プロンプトを作る

### ACTION

今週うまくいったAI活用を、

3つテンプレート化する。


例：

```text
メール作成

要約

企画壁打ち
```


### DONE CONDITION

次回コピペして使えるプロンプト3つ。


---

## Day7｜自分のAI仕事フローを決める

### ACTION

7日間を振り返る。

今後もAIを使う仕事を、

3つ決める。


### LINE REPORT

```text
7日間完了！

一番変わったこと：
○○

一番役立った使い方：
○○

次にやってみたいこと：
○○
```


---

## 30日後の目標

- 毎週AIを使う仕事が5つ以上
- プロンプトが5〜10個ある
- AIを使う仕事 / 使わない仕事を判断できる


---

## 90日後の方向性

複数工程をAIと進める。


例：

```text

↓

↓
タスク抽出
↓

↓
次回アジェンダ
```

## 今やらなくていいこと

- プロンプトを100個集める
- 難しい自動化
- コーディング学習


---

## 次のステップ

ChatGPT仕事活用入門｜AI初心者が実務で使えるようになる実践講座**

# 21. SUB TYPEとの関係

ロードマップ本体は、

```text

```

で固定。


SUB TYPEは、

ロードマップ前の、

「あなたの強みの使い方」

で補足する。


例：

```text
MAIN
creator

SUB
builder

GOAL
side
```


主要ルート：

```text

```


補足：

```text
AIビルダー要素が強いため、

通常の制作だけでなく、

Webアプリや診断など
「動く制作」にも発展させやすいタイプです。
```

# 25. 最重要原則

ロードマップの目的は、

情報を大量に渡すことではない。


目的は、

**「今日何をすればいいか分かる」**

こと。


無料なのに、

```text
ここまで具体的に教えてくれるん？
```

と思ってもらえる濃さを目指す。


ただし、

ユーザーを情報量で圧倒せず、

毎日、

```text
1テーマ
1アクション
1完了
```

を基本とする。
